# Credits

Authored and maintained by Dean van Niekerk.

Adapted from [Theo Browne's council](https://github.com/t3dotgg/tstack/blob/main/skills/council/SKILL.md): one strong model per provider, reporting rather than substituting a missing member, checking verdicts while the rest run, non-blocking members, rounds of review until every member is satisfied, the PR score table, and holding the line on scope. This version generalises it from code review to any subject, and adds the evidence step, the shared brief and verdict shape, the adopt/decline/ask sort, and a three-round cap. No text is copied.
