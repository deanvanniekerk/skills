# Credits

Authored and maintained by Dean van Niekerk from his spec delivery workflow.

Reading the tickets as a task graph and working whichever are ready is inspired by [Matt Pocock's implement-spec skill](https://github.com/mattpocock/skills). `tackle-spec` differs in delivering each ticket as its own reviewed, merged PR through `tackle-issue`, tightening each ticket before it starts, and finishing with `quality-control`. No text from it is copied into this folder.

It orchestrates skills installed separately:

| Skill | Source |
| --- | --- |
| `tackle-issue`, `quality-control` and what they chain | This collection, and the sources their credits name |

Subagents run through [T3 Code](https://github.com/pingdotgg/t3code). Third-party projects keep their own licenses.
